# 🌿 Mental Wellness Companion

An AI-powered mental wellness web app built with **Streamlit**, helping users to improve emotional well-being through **chatbot conversations, mood tracking, journaling, and self-assessment surveys**.

---

## ✨ Features

- 🤖 **AI Chatbot** – A supportive chatbot powered by AIML that engages in wellness conversations.  
- 📊 **Mood Tracker** – Track your daily mood and visualize emotional trends over time.  
- 📓 **Journaling** – Write daily thoughts and get automatic **sentiment & emotion analysis**.  
- 🧾 **Self Assessment** – Predict potential mental health risks with a trained ML model.  
- 🎨 **Beautiful UI** – Clean interface with stylish buttons and charts for an engaging experience.
